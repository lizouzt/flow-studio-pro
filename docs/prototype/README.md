# Flow Studio Pro · 高保真设计原型 (Interactive Prototype)

这是用于体验 **电影工业级暗色质感（Cinematic Dark Aesthetic）** 界面与 4 步工作流的高保真交互原型。

---

## 🚀 如何体验？

直接在浏览器中打开：
```text
story-studio-web/docs/prototype/index.html
```

---

## ✨ 原型包含的核心交互点

1. **4 步流转胶囊导航**：
   - 点击顶部的 `1. 撰稿与配音`、`2. 分镜与首帧`、`3. 视频回填`、`4. 剪映装配`，切换全流程视图。
2. **Step 1: 文案与百炼调音台**：
   - 包含短视频口播编辑器、CosyVoice 音色选择、语速滑块、动态声波仿真。
3. **Step 2: 9:16 镜头分镜看板 (Storyboard Grid)**：
   - 电影暗色毛玻璃卡片（Amber Glow 悬浮光效）；
   - 9:16 竖屏首帧图展示与 Hover 重绘操作；
   - 动力学运镜与动作提示词标签，点击“复制”有实时的浮动 Toast 反馈。
4. **Step 3: 外部视频中转站与全景 Dropzone**：
   - 专为 Google Flow / 即梦 Seedance 设计的批量拖拽回填区；
   - 视频就绪状态绿色指示卡。
5. **Step 4: 剪映草稿装配**：
   - 时长自适应与动静混剪开关；
   - 点击“开始构建剪映专业版草稿”，可触发模拟装配并展示交付卡片。
6. **右上角配置抽屉**：
   - 点击右上角齿轮图标，滑出百炼 API Key 与云端 Whisper 端点配置面板。
